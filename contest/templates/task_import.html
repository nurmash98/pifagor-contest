⬆ Импорт задач из JSON

Загрузите файл .json или вставьте текст. Можно сразу много задач (до {{ max_tasks }}). Если хоть в одной задаче ошибка — ничего не импортируется, сайт покажет, что исправить.

{% csrf_token %}
Формат
  • title, level (A/B/C), description, input_example, output_example — обязательно.
  • test_cases — тесты для автопроверки (до {{ max_tests }}), по желанию. Без тестов задачу проверяет учитель.
  • tags — список тегов, новые создаются сами.
  • title_kk, description_kk, input_example_kk, output_example_kk — казахская версия, по желанию.
  • Задачи с названием, которое уже есть на сайте, не принимаются. Лишние поля (например id, hint) просто игнорируются.
  • Перенос строки внутри текста — \n. Ответы лучше делать на английском или числами, одинаковыми для RU и KZ.
Пример
[
  {
    "title": "Сумма двух чисел",
    "level": "A",
    "description": "Даны два числа, каждое на отдельной строке. Выведите их сумму.",
    "input_example": "2\n3",
    "output_example": "5",
    "tags": ["input/output"],
    "test_cases": [
      {"input": "1\n1", "output": "2"},
      {"input": "10\n-4", "output": "6"},
      {"input": "0\n0", "output": "0"},
      {"input": "100\n200", "output": "300"},
      {"input": "-5\n-5", "output": "-10"}
    ],
    "title_kk": "Екі санның қосындысы",
    "description_kk": "Екі сан берілген, әрқайсысы жаңа жолда. Олардың қосындысын шығарыңыз."
  }
]
